دفتر دعای من — پروژه اندروید
==============================

این فایل ZIP یک پروژه اندروید است، نه APK آماده. این محیط ابزار Android SDK/Gradle برای کامپایل مستقیم ندارد؛ بنابراین APK آماده در این ZIP نیست.

روش ساخت APK:
1) فایل ZIP را از حالت فشرده خارج کنید.
2) پوشه را در Android Studio باز کنید (Open).
3) اجازه دهید Gradle Sync انجام شود و SDK 35 و JDK 17 نصب باشند.
4) از منوی Build > Build Bundle(s) / APK(s) > Build APK(s) استفاده کنید.
5) APK معمولاً در app/build/outputs/apk/debug/app-debug.apk ساخته می‌شود.
6) فایل APK را به گوشی منتقل کنید و نصب کنید. ممکن است لازم باشد اجازه نصب از منبع موردنظر را در تنظیمات اندروید فعال کنید.

راه ساده‌تر با GitHub Actions:
1) محتویات این پوشه را در یک مخزن GitHub جدید آپلود کنید.
2) تب Actions را باز کنید و workflow با نام Build Android APK را اجرا کنید (یا یک commit به main بفرستید).
3) پس از پایان موفق، از بخش Artifacts فایل daftar-doaye-man-apk را دانلود کنید و APK را از داخل آن بردارید.

امکانات:
- برنامه Android با آیکون اختصاصی سبز/کرم
- محتوای دعا به صورت آفلاین داخل اپ
- افزودن، ویرایش، حذف و جست‌وجوی دعا
- عربی، تلفظ فارسی، ترجمه و منبع
- داده‌ها در فضای ذخیره‌سازی WebView همین اپ نگهداری می‌شوند

توجه:
- این نسخه آزمایشی است و هنوز در Google Play منتشر نشده.
- از خروجی پشتیبان در خود برنامه استفاده کنید تا دعاها را از دست ندهید.
- متن بعضی مناجات‌هایی که از گفت‌وگو وارد شده‌اند، پیش از استفاده رسمی باید با منبع چاپی تطبیق داده شوند.
